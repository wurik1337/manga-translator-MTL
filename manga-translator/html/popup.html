Подключение локальной LLM (OpenAI-compatible)

1. LM Studio — вкладка Local Server → Start Server. Адрес: http://127.0.0.1:1234/v1. Имя модели подставится кнопкой «Проверить соединение».

2. Ollama — запусти OLLAMA_ORIGINS=* ollama serve, адрес: http://127.0.0.1:11434/v1, модель например qwen2.5:3b.

3. Unsloth (Windows) — после файнтюна запусти сервер OpenAI-compatible (например через llama.cpp server / llama-server или vLLM): llama-server -m model.gguf --port 8080, адрес: http://127.0.0.1:8080/v1.

Перевод идёт простым промптом с нумерованными строками — подходят даже модели 1B–2B. Все данные остаются на твоём компьютере: расширение шлёт только текст пузырей на твой локальный адрес.

Vision OCR — тумблер в настройках API Mode: пузыри находит локальная модель детекции, а читать текст и переводить его будет модель с поддержкой изображений (qwen2.5-vl, gemma-3, llava, gpt-4o-mini…). OCR-модель и отдельный переводчик не нужны.
